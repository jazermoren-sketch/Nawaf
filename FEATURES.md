# Requested features

1. المشرف يكتب من البوت ويحدد الروم.
2. إرسال رسالة يحددها المشرف إلى الأعضاء.
3. Tickets: عند إغلاق التذكرة يظهر تقييم 1-5 وملاحظة لصاحب التذكرة.
4. XP وLevels للأعضاء.
5. Applications + Announcements.
6. Automatic Dhikr with configurable channel and interval.
7. Server-specific custom currency with configurable name/symbol, balance, transfer, and admin grants.

## Stack
Python / discord.py 2.x / SQLite.
