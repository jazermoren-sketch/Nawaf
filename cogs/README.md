# Cogs

كل نظام مستقل في Cog خاص به، مع قاعدة SQLite مشتركة في `database.py`.

- `messages.py`: إرسال رسائل إلى روم محدد.
- `tickets.py`: التذاكر والتقييم والملاحظة.
- `leveling.py`: XP والمستويات.
- `applications.py`: التقديمات.
- `announcements.py`: الإعلانات.
- `dhikr.py`: الأذكار التلقائية.
- `economy.py`: العملة الخاصة بالسيرفر.
